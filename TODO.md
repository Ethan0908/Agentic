# Autonomous Improvement Backlog
## Current priorities
Find and fix important correctness or reliability problems. 
Improve error handling where clearly needed. Improve meaningful 
automated test coverage.
## Continuous maintenance
When no explicit priority task remains, inspect: - failing tests 
- TODO comments - FIXME comments - type errors - lint errors - 
duplicated logic - weak error handling - missing tests - obvious 
performance problems - outdated or incorrect documentation
Do not invent features simply to produce work.
