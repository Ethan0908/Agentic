# Website Builder Quality Notes

These notes describe the product standard the generator should enforce.

## Principles

1. **Scannability beats long copy.** The generated page should use meaningful headings, short paragraphs, bullets, and cards. Avoid wall-of-text sections.
2. **Objective copy beats hype.** Generic promotional language reduces trust. Write specific, practical statements instead.
3. **The hero must answer the buyer's first questions.** What service is this? Where does it operate? Why should I trust it? What action should I take?
4. **Trust must be real.** Do not invent licences, awards, review counts, years in business, warranties, emergency availability, or guarantees.
5. **Design should create confidence.** Use clean hierarchy, generous spacing, restrained colour, strong contrast, and responsive layout.
6. **Performance is part of quality.** Keep the template static, light, and stable. Avoid large dependencies or visual effects that cause layout shift.

## High-converting local service page structure

1. Sticky header with service area and CTA.
2. Hero with specific headline, concise subheadline, CTA pair, and 3 trust bullets.
3. Proof strip.
4. Services cards.
5. Why choose / decision criteria.
6. Process after contact.
7. Reviews if supplied; expectations if not supplied.
8. FAQ for objections.
9. Final CTA.
10. Footer with business and service area.

## Copy rules for generated sites

- Keep most paragraphs under 28 words.
- Use one idea per paragraph.
- Use direct verbs.
- Avoid vague claims.
- Prefer process proof when hard proof is missing.
- Use local terms naturally.
- Make CTA language match the business type.

## Visual rules for generated sites

- No cheap stock-template feel.
- No cluttered hero.
- No fake review blocks.
- No decorative sections without a conversion purpose.
- Mobile CTA should remain obvious.
- Avoid too many colours; use a restrained palette.
